# Mouse 3D Reconstruction

基于多视角图像的目标三维重建与空间坐标处理项目。

本项目主要用于学习三维重建、空间坐标解析以及 PyTorch 基础训练流程。通过对目标物体进行多角度图像采集，完成三维模型重建，并基于生成的空间数据实现目标轨迹跟随与简单训练任务。

## 已实现功能
* **多视角图像采集**
* **COLMAP 三维重建**
* **MeshLab 模型处理**
* **Python 二进制数据解析**
* **三维坐标提取**
* **地形跟随逻辑**
* **PyTorch 基础模型训练**

## 技术栈
* **Python**
* **PyTorch**
* **COLMAP**
* **MeshLab**
* **NumPy**

## 项目流程

### 1. 数据采集
对目标物体进行多角度图像拍摄，构建重建所需数据集。

### 2. 三维重建
使用 COLMAP 完成稀疏/稠密重建，并通过 MeshLab 进行模型清洗、网格化等处理。

### 3. 空间数据解析
使用 Python 编写脚本读取 COLMAP 生成的二进制数据（如 `points3D.bin`），并精确提取三维空间坐标信息。

### 4. 地形跟随
基于提取的坐标数据，实现目标在生成的场景中进行动态位置更新与简单的轨迹跟随逻辑。

### 5. PyTorch 训练
构建轻量级神经网络模型，针对提取的空间坐标分布进行基础学习与预测实验。

## 项目目的

本项目主要用于学习与实践以下领域：
* **三维重建流程**：掌握从多视角照片到 3D 模型的完整 Pipeline。
* **空间数据处理**：理解三维点云数据在不同坐标系下的表示与变换。
* **Python 数据解析**：学习高效处理二进制底层数据。
* **PyTorch 基础训练**：实践深度学习在空间信息处理中的初步应用。
* **视觉与空间信息结合**：探索如何将视觉重建成果转化为可用的空间感知数据。
